## [Hugging Face Transformers 漏洞在同意前写入远程代码](https://kb.cert.org/vuls/id/456290) ⭐️ 8.0/10

Hugging Face Transformers 4.49.0 至 5.8.1 版本中存在一个漏洞（CVE-2026-80047），允许远程 Python 文件在 trust_remote_code 同意检查之前被写入磁盘。这影响了 load_custom_generate() 方法，该方法无条件地获取并缓存远程代码。 这很重要，因为 Transformers 是 AI/ML 社区广泛使用的库，该漏洞可能导致用户系统上持久存在未经授权的文件，在某些情况下可能实现任意代码执行。它破坏了 trust_remote_code 的安全契约，影响众多开发者和组织。 该漏洞的发生是因为库在通过 resolve_trust_remote_code() 评估同意之前，先通过 get_cached_module_file() 获取并缓存远程模块。文件写入是无条件的且无法回滚，这与其他加载机制（如 AutoConfig 和 AutoModel）不同，后者会先检查同意。

rss · CERT CC Vulnerability Notes · Sep 1, 13:35

**背景**: Hugging Face Transformers 是一个流行的开源库，用于构建和使用机器学习模型，包括 NLP、视觉和多模态系统。trust_remote_code 功能允许用户从模型仓库加载自定义代码，但需要用户明确同意以防止恶意代码执行。该漏洞绕过了文件写入步骤的同意，即使用户拒绝，也会在磁盘上留下恶意文件。
