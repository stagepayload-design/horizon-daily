## [WordPress 修复可导致条件性 RCE 的未认证路径遍历漏洞](https://github.com/WordPress/wordpress-develop/security/advisories/GHSA-7hp8-65ch-5whp) ⭐️ 9.0/10

WordPress 发布了一个安全修复，针对一个可导致条件性远程代码执行（RCE）的未认证路径遍历漏洞，该补丁已在 7.1.2 版本中修复，并向后移植到 4.7 以来的所有分支。 WordPress 驱动着互联网上极大比例的网站，一个可升级为远程代码执行的未认证漏洞会让数百万站点面临风险，尤其是约三分之一的安装仍运行较旧分支，只能依赖向后移植的补丁。 该漏洞属于路径遍历问题，即攻击者可以操纵文件路径以访问预期目录之外的文件，而“条件性 RCE”意味着代码执行取决于特定的服务器配置或文件写入条件；补丁提交可在 WordPress develop 仓库中查看。

hackernews · vntok · Sep 22, 16:33 · [社区讨论](https://news.ycombinator.com/item?id=49803959)

**背景**: 路径遍历是一类 Web 漏洞，当应用程序使用用户提供的输入构建文件路径而未进行适当验证时，攻击者就能利用“../”等序列跳出预期目录。远程代码执行（RCE）是指攻击者能在目标服务器上运行任意代码，通常是 Web 漏洞最严重的后果。WordPress 是广泛使用的开源内容管理系统，其安全团队会定期将修复向后移植到较旧的发布分支，以保护尚未升级到最新主版本的站点。
