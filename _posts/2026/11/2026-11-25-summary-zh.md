## [Rapid7 披露 VMware vCenter SRP 认证绕过漏洞可获取 root 权限 (CVE-2026-123890)](https://www.rapid7.com/blog/post/ra-rapid7-analysis-vmware-vcenter-srp-authentication-bypass-to-root-cve-2026-123890) ⭐️ 9.0/10

rss · Rapid7 Emergent Threat Response · Nov 24, 13:01

**背景**: VMware vCenter 的目录服务使用安全远程密码（SRP）协议，这是一种密码认证密钥交换协议，通常能防止攻击者在不知道密码的情况下获知会话密钥。DCE/RPC 是 vCenter 服务使用的远程过程调用协议，端口 2012 是 vCenter 单点登录（SSO）的控制接口。UUIDv1 标识符嵌入了时间戳，如果攻击者能观察相关值，它们就变得可预测。

## [针对 Check Point 安全管理服务器的活跃入侵活动](https://www.greynoise.io/blog/check-point-security-management-servers-intrusion-campaign) ⭐️ 8.0/10

GreyNoise 报告了一起针对 Check Point 安全管理服务器的活跃入侵活动（编号 GT13），攻击者利用 PRNG 状态重建技术伪造管理员会话 cookie。攻击者通过收集 Node.js V8 中 JavaScript Math.random()的输出，恢复会话 cookie 签名密钥，并为 HFS 服务器伪造签名管理员 cookie。 该活动凸显了一条复杂的攻击链，结合了初始访问漏洞（可能是 CVE-2026-16232）与广泛使用的 JavaScript PRNG 中的新型密码学弱点，可能影响许多暴露管理接口的组织。它强调了国家级别或高级攻击者利用 LLM 和自动化扩大攻击规模的风险日益增长。 攻击涉及扫描并利用 HFS 的 loginSrp1 端点，每次 POST 返回一个包含 Math.random()生成的'sid'的新签名会话 cookie；通过多次登录，攻击者重建了 V8 PRNG 的内部状态。Check Point 服务器的初始访问途径尚未确定，但多个客户被攻陷表明 CVE-2026-16232 可能是入口点。

hackernews · louiereederson · Nov 24, 16:32 · [社区讨论](https://news.ycombinator.com/item?id=50630594)

**背景**: Check Point 安全管理服务器是用于管理企业网络安全的中央控制台。像 JavaScript 的 Math.random()这样的 PRNG（伪随机数生成器）并非密码学安全，如果其内部状态可以从输出中重建，攻击者就能预测未来值。CVE-2026-16232 是 Check Point SmartConsole 中的一个认证绕过漏洞，允许攻击者获得管理访问权限。

## [Quad9 因法律限制从法国撤出公共 DNS 服务](https://quad9.net/news/blog/quad9-service-deactivation-in-france/) ⭐️ 8.0/10

瑞士非营利公共 DNS 解析器 Quad9 于 2026 年 11 月 24 日起在法国停用其服务，返回带有扩展 DNS 错误代码 18（禁止）的 REFUSED 响应，并注明原因是法国法律限制。此次撤出源于法院命令要求 Quad9 屏蔽盗版流媒体网站，而该组织选择不遵守该命令。 这为法律屏蔽命令如何迫使公共 DNS 解析器退出整个司法管辖区开创了先例，可能影响法国数百万依赖 Quad9 获取隐私和安全的用户。它凸显了国家内容屏蔽法律与全球互联网基础设施之间日益紧张的关系，并可能促使其他解析器重新考虑在限制性市场的存在。 Quad9 的撤出已通过 DNS 查询返回 REFUSED 状态及 EDE 18 得到确认，且该服务此前因缺乏地理围栏资源而在全球范围应用了法国的屏蔽命令。社区成员已建立替代代理（如 quad9.domainintelligence.uk），为受影响用户提供直接替代方案。

hackernews · farrokhi · Nov 24, 08:33 · [社区讨论](https://news.ycombinator.com/item?id=50625384)
