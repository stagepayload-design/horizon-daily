## [Cloudflare 收购 Deno，运行时开发将在一年后终止](https://deno.com/blog/cloudflare) ⭐️ 9.0/10

Cloudflare 已收购 Deno，Deno 团队宣布 Deno 运行时在未来一年内仅会收到每月的错误修复和安全更新，一年后 Cloudflare 将终止对该运行时的开发。Deno 仍将保持开源，但其后续发展将取决于社区或其他维护者是否接手。 这对 JavaScript 和 TypeScript 生态系统而言是一大事件，因为 Node.js 最知名的替代运行时之一在被收购方转移重心后实际上正被逐步关停。基于 Deno 构建应用的开发者如今面临长期支持的不确定性，这一结果也可能影响整个 JS 运行时领域未来的创新与竞争程度。 这一年的支持期包括每月发布包含错误修复和安全更新的版本，之后 Cloudflare 将完全停止开发该运行时。Deno 仍保持开源，社区可以自由继续其开发，但若没有专门的维护者，它将不再获得官方支持。

hackernews · ilreb · Oct 9, 13:03 · [社区讨论](https://news.ycombinator.com/item?id=50019911)

**背景**: Deno 是由 Node.js 原作者 Ryan Dahl 创建的 JavaScript 和 TypeScript 开源运行时，旨在成为更安全、更现代的替代方案，内置开发工具并原生支持 TypeScript。Cloudflare 运营着大型边缘网络，并开发了在其基础设施上运行 JavaScript 的无服务器平台 Cloudflare Workers，因此这次收购是运行时人才与技术的一次整合。

Cloudflare 扩展了其 Clef 决策模型家族，新增 Clef-omni，可在单一流水线中原生处理音频、视频、图像和文本，同时将 Clef 的推理速度提升最高 2.0 倍，并降低了 Clef-flash 的价格。 这为开发者提供了一个单一的开源权重模型，可将多模态状态转化为带类型的概率决策，对于构建多模态智能体和 AI 基础设施很有价值，无需再拼接独立的视觉、音频和文本模型。速度和价格的改进也降低了在 Cloudflare Workers AI 上大规模运行决策模型的成本。 Clef-omni 基于 300 亿参数的混合专家（MoE）骨干网络，激活参数为 30 亿，是 Qwen3-Omni-30B-A3B 的微调版本，可将状态读取为文本、JSON、图像、音频或视频，并为每个带类型问题的每个允许选项返回概率。较小的 Clef-flash 约有 94 亿参数，该系列在 Workers AI 上提供服务，权重采用 Apache 2.0 许可。

rss · Cloudflare Blog · Oct 9, 18:27

**背景**: Cloudflare Workers 是一个在边缘运行 JavaScript 的无服务器平台，而 Durable Objects 通过将计算与存储结合在用户附近来提供有状态协调。火焰图是一种常见的性能分析可视化方式，显示程序不同部分消耗的时间或内存，从而更容易发现低效之处。此前，开发者在生产环境中分析这些工作负载的能力有限，通常依赖本地测试或间接指标。

## [研究：GitHub 智能体技能副本被采用 219 万次，却极少更新](https://huggingface.co/papers/2610.11169) ⭐️ 7.0/10

一项新研究发现，GitHub 智能体技能的副本被采用约 219 万次，但这些副本极少从原始来源拉取更新，因此上游所做的修复很难传递到复制版本中。 这一点很重要，因为随着智能体越来越依赖社区共享的技能，存在漏洞或过时的技能副本可能在整个 AI 智能体生态中广泛存续，带来供应链完整性与安全风险。 该发现揭示了技能复制网络中的传播缺口：即使源技能被修补，下游副本也不会自动同步，这意味着 219 万次的采用规模并不能转化为一致的安全维护。

rss · BALA AI News · Oct 9, 19:01

**背景**: 智能体技能是让 AI 编程智能体获得专门工作流和最佳实践的可复用指令包，通常通过公开的 GitHub 仓库（如 Anthropic 的 skills 仓库）共享。由于这些技能很容易被复制和再分发，它们会通过一个复制网络传播，其中每个副本都是独立快照，而非指向原始版本的实时链接。本研究考察了这种复制行为如何影响上游修复能否到达众多下游副本。
