## [PHP2Shell 与 Linux XFRM 漏洞链攻陷 25 台服务器](https://dreamgroup.com/blog/chained-php2shell-exploit-roots-25-servers) ⭐️ 8.0/10

根据 Dream Group 的一篇博客文章，一个结合 PHP2Shell 和 Linux 内核 XFRM ESP-in-TCP 漏洞的链式利用据称攻陷了 25 台服务器，其中包括美国政府系统。该攻击将基于 PHP 的 Web 漏洞利用与 Linux 内核中的本地权限提升链接起来，从而完全控制了受影响的主机。 该事件凸显了将 Web 应用漏洞与内核级权限提升链接起来的复合风险，使攻击者能够从初始访问升级到完全的 root 控制。它还引发了对 Linux 网络子系统（如 XFRM 和 MPTCP）默认启用攻击面的担忧，而许多用户根本不需要这些功能。 Linux 内核漏洞被标识为 CVE-2026-46300（Fragnesia），是 XFRM ESP-in-TCP 子系统中的一个高危本地权限提升漏洞（CVSS 7.8），可通过 AES-GCM 密钥流操纵实现受控的页缓存破坏。PHP2Shell 组件可能指的是最近修补的 PHP 漏洞，这些漏洞被用于攻击暴露在互联网上的管理接口，例如 Palo Alto Networks 产品中的接口。

hackernews · 882542F3884314B · Oct 29, 10:42 · [社区讨论](https://news.ycombinator.com/item?id=50286987)

**背景**: PHP2Shell 指的是一类利用 PHP 应用程序（通常是 WordPress 插件）中的漏洞来实现远程代码执行的漏洞利用。Linux 内核的 XFRM ESP-in-TCP 子系统处理封装在 TCP 中的 IPsec ESP 数据包，其中的缺陷可能允许具有本地访问权限的攻击者提升至 root 权限。将 Web 漏洞利用与内核本地权限提升链接起来，是将 Web 入侵转化为完全服务器接管的一种常见技术。

rss · CISA Cybersecurity Advisories · Oct 29, 12:00
