## [Cloudflare 在分析与日志中新增后量子加密可见性](https://blog.cloudflare.com/post-quantum-visibility/) ⭐️ 7.0/10

Cloudflare 已在 HTTP Analytics、Log Explorer 和 Logpush 中直接加入对 TLS 1.3 后量子（PQ）加密的可见性，让客户能够查看其域名下已使用后量子加密的访客连接百分比，该加密通过混合密钥交换组 X25519MLKEM768 实现。 随着量子计算的发展，组织需要验证其流量是否能够抵御未来的量子攻击，而该功能为他们提供了一种实用的、逐连接的测量域名后量子采用率的方法。它把抽象的威胁转化为可观测的指标，从而降低了安全团队为后量子过渡做准备的难度。 该可见性功能可识别协商的密钥交换组，包括 TLS 1.3 混合 X25519MLKEM768，并可通过 HTTP 流量分析仪表板、Logpush 和 Log Explorer 使用。客户还可以检查日志，以确认其连接是否正在使用后量子加密。

rss · Cloudflare Blog · Sep 29, 13:00

**背景**: 后量子密码学是指旨在抵御未来量子计算机攻击的加密算法，因为量子计算机可能破解当今广泛使用的公钥密码学。TLS 1.3 是用于保护 HTTPS 连接的最新版传输层安全协议，而像 X25519MLKEM768 这样的混合密钥交换将经典算法（X25519）与后量子算法（ML-KEM，原 Kyber）结合，即使其中一种被攻破，连接仍能保持安全。Cloudflare 的 Logpush 可将日志推送到存储服务、SIEM 和日志管理提供商，而 Log Explorer 则允许客户使用类似 SQL 的查询搜索 Cloudflare 日志。

## [Cloudflare 推出应用配置文件，实现正向安全防护](https://blog.cloudflare.com/application-profiles/) ⭐️ 7.0/10

Cloudflare 发布了应用配置文件（Application Profiles），这是一项新的正向安全功能，能够学习 HTTP 请求的正常结构并标记偏离基线的异常行为。该功能旨在应对 AI 让攻击者更容易生成和变换恶意载荷的趋势，从而缩小攻击面。 这一点很重要，因为传统的基于签名和规则的 WAF 难以应对 AI 生成、不断变异的载荷，而正向安全模型提供了一种互补的防御层。作为主要的 CDN 和安全厂商，Cloudflare 的采用可能会推动正向安全建模成为 Web 应用防护的主流做法。 应用配置文件通过学习 HTTP 请求的预期结构并识别偏离来工作，而不是仅依赖已知的恶意模式。它是对 Cloudflare 现有 WAF 的增量补充，而非独立替代方案，因此应被视为额外的一层防御。

rss · Cloudflare Blog · Sep 29, 13:00

**背景**: Web 应用防火墙（WAF）通常检查传入流量中的已知攻击签名或可疑模式，这被称为负向安全。正向安全则采取相反的方法：它定义正常流量应该是什么样子，并阻止或标记任何不匹配的流量，从而能够捕获缺乏已知签名的新型或混淆攻击。AI 生成的载荷日益令人担忧，因为攻击者可以利用 AI 快速生成大量攻击变体，使基于签名的检测效果下降。
